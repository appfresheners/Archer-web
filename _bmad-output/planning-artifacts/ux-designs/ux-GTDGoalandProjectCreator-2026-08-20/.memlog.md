- (decision) Primary CTAs: Copy Markdown, Download .md. Output is Notion-optimized markdown.
- (decision) Zero friction: no account, no auth, no tracking. Free forever public tool.
- (decision) MVP1: No AI/LLM. Pure template generation with user input slotted in. Single text input per mode.
- (decision) Working mode: Fast path selected. Batch assumptions, skip creative tools.
- (assumption) Stakes: passion project / public good. No regulated content, no payments, no PII.
- (assumption) UI system: Tailwind utility-first with no component library (shadcn, MUI, etc.) specified. Assuming custom lightweight components.
